## Layout

```
notes/
├── pages/        <- the 28 note images (the deliverable)
├── src/
│   ├── render.py <- Pillow notebook-page renderer (paper, ink, boxes, arrows)
│   ├── build.py  <- renders every content module to pages/
│   └── content/  <- v01.py .. v28.py : the actual notes text
├── assets/       <- OFL handwriting fonts (Kalam, Caveat, Patrick Hand, ...)
└── index.html    <- browser gallery of all pages
```

Rebuild: `cd notes/src && python3 build.py` (needs Pillow).
